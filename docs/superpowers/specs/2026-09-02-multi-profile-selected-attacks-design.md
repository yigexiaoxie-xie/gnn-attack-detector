# 多数据集与多攻击分批运行设计

## 目标

把当前只能通过 `active_profile` 处理一个数据集、并且默认运行全部攻击的流程，改为一次可以选择多个数据集和多个攻击方法。平台支持目录与本次运行选择分离：攻击或数据集即使在本次被注释掉，仍保留在代码注册表中，下一次取消注释即可执行。

最终仍训练一个通用完整图二分类检测器。每个数据集拥有自己的干净参考图和探针模型，但不拥有单独的最终检测器。

## 配置边界

`configs/base.yaml` 保存稳定的完整目录与训练参数：

- 数据集档案：`cora-lcc`、`citeseer-lcc`、`polblogs-lcc`、`pubmed-lcc`；
- 攻击注册目录；
- 强度、样本配额、模型和评测门槛；
- 所有路径均为项目内相对路径。

新增 `configs/run.yaml`，只描述本次任务。所有可选数据集和攻击方法均逐行列出；没有 `#` 的行本次执行，有 `#` 的行本次跳过。例如：

```yaml
run:
  profiles:
    - cora-lcc
    - citeseer-lcc
    # - polblogs-lcc
    # - pubmed-lcc

  attacks:
    - random_add
    - dice_mix
    # - igattack

  partitions:
    - train
    - val
    - test
```

YAML 注释只负责让用户选择；真正的可用目录以 Python 注册表和 `base.yaml` 为准。加载时必须拒绝空列表、重复项、未知数据集、未知攻击和未知数据分区。

## 数据集档案

四个档案统一使用 DeepRobust 的最大连通分量口径，并分别保存：

- 干净图；
- GCN、GCN-Jaccard、SimPGCN 探针检查点；
- 数据划分与图指纹；
- 该档案的攻击清单和图级特征。

数据集形状由首次下载和规范化结果验证。配置中的预期节点数用于发现下载、预处理或档案混用错误，不能在运行时静默截断或补齐。Polblogs 没有原生节点属性时，由数据适配层使用固定、可复现的结构特征，不在攻击器内临时构造。

## 运行流程

新增一个选择式运行入口。它读取 `base.yaml` 与 `run.yaml`，计算所有启用数据集和攻击方法的笛卡尔积。例如两个数据集和三个攻击方法形成六个独立组合。

第一阶段对每个组合依次执行：

1. 准备或复用该数据集档案与探针；
2. 按选择生成或复用训练、验证扰动图；
3. 更新该数据集独立清单；
4. 输出该组合的完成数量和失败原因。

所有训练、验证组合处理完成后，只训练一次通用检测器。模型和阈值冻结以后，再为启用了 `test` 的组合生成或复用测试图并进行评测。若只选择 `test` 但尚不存在冻结检测器，入口直接报告缺少模型，不会临时使用测试集训练。单个组合失败不能删除或覆盖其他组合的结果；运行结束时输出成功、复用和失败组合汇总，并在存在失败时返回非零状态。

## 续跑与隔离

每张图的唯一身份由数据集、分区、攻击、强度、样本序号和随机种子共同确定。文件路径必须显式包含数据集 ID：

```text
artifacts/attacks/corpus/<profile>/<partition>/<attack>/<sample>.pt
```

清单保持每个数据集一份：

```text
artifacts/features/manifests/<profile>.jsonl
```

重新执行同一选择时，只有图指纹、审计字段和预期配额都一致的文件才能标记为复用。已存在但不完整、不兼容或损坏的文件不能被静默接受。

## 样本数量

普通攻击在每个“数据集 × 攻击”组合中按四档强度生成 20 张：训练 8 张、验证 4 张、测试 8 张。PGDAttack 使用 12 张：训练、验证、测试各 4 张。Metattack 默认使用四档强度各一张预计算测试图，共 4 张。

启用多个数据集和多个攻击时，数量按组合相加。注释掉的条目不计入本次配额。报告按所选数据集和攻击方法统计测试结果。

## 失败处理

- 下载失败：保留其他档案和图，报告具体数据集；
- 缺少预计算 Metattack：只将对应组合标记失败，不在线生成耗时的替代图；
- 不兼容数据形状：拒绝加载并指出实际值与档案值；
- 攻击生成失败：保留已经写入并校验成功的样本，下一次从缺口继续；
- 训练前：只纳入分区、档案、哈希与配额校验通过的记录，防止训练/测试泄漏。

## 用户入口

Windows 服务器提供一个批处理入口：

```powershell
.\scripts\run_selected_attacks.bat
```

用户日常只编辑 `configs/run.yaml`。脚本不要求复制配置、不要求逐条输入命令，也不删除 `artifacts` 中未被本次选择的数据。

## 验证

- 配置测试：允许多个数据集和多个攻击，拒绝空项、重复项和未知项；
- 选择测试：只产生未注释条目的笛卡尔积；
- 续跑测试：相同组合复用，新增选择只补新增组合；
- 隔离测试：不同数据集的文件路径和清单不冲突；
- 失败测试：一个组合失败后其他组合仍可完成，最终汇总返回失败；
- 注册测试：21 个攻击 ID 唯一且包含 IGAttack；
- 轻量自动测试不下载真实数据；服务器再运行四数据集的真实准备、生成和评测。

## 非目标

- 本轮不保证一次在 CPU 上生成全部四数据集、全部 21 种攻击能在两小时内完成；选择式执行正是为分批续跑。
- 本轮不把未知数据集自动映射到已有档案。
