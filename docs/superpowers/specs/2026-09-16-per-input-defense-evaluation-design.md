# 每张扰动图独立训练防御模型设计

## 目标

平台选择任意防御模型并输入一张扰动图后，使用对应 DeepRobust 数据集的
`idx_train`、`idx_val`、`idx_test`，从头训练该防御模型并报告测试节点准确率。
防御评测与共享攻击检测器完全隔离。

## 数据协议

- 用户仍选择 Cora、CiteSeer、PubMed 或 PolBlogs 数据集档案。
- 平台从该档案的 `clean.pt` 读取 DeepRobust 原始标签和节点划分。
- 上传图只提供扰动后的 `edge_index`，以及存在时的扰动后节点属性 `x`。
- 平台拒绝节点数或特征维数与所选档案不一致的图。
- 训练、验证和测试标签一律使用可信的 DeepRobust 数据，不接受上传文件覆盖。

## 运行协议

- GCN、GCN-Jaccard、GCN-SVD、RGCN、MedianGCN、SimPGCN、GNNGuard、
  AirGNN、SGC 均对干净图和当前扰动图分别新建模型、使用相同随机种子和相同
  DeepRobust 划分训练，再分别计算测试准确率。
- ProGNN采用相同划分执行每图结构优化；节点数超过5000时继续拒绝，避免稠密
  邻接矩阵导致内存溢出。
- 每次评测的模型参数只存在于当前进程内，结果返回后丢弃，不保存检查点。
- CUDA优先；训练失败时沿用现有CPU回退机制。

## 平台行为

- 防御页不再要求运行 `prepare-defenses` 或检查防御检查点。
- 只要所选数据集的可信干净档案存在，该防御模型即可运行；缺失实现或超出
  ProGNN节点上限时显示明确错误。
- 页面明确提示每张输入图都会重新训练，因此运行时间取决于模型和图规模。

## 不在范围内

- 不修改共享攻击检测器、检测阈值、检测训练语料或攻击生成流程。
- 不删除旧防御检查点；新评测流程只是不再读取它们。
- 不把只有边且无法匹配已知数据集档案的任意图伪装成可监督评测输入。

## 验证

- 单元测试证明所有模型均路由到每图训练路径。
- 单元测试证明划分来自 `clean.pt` 的DeepRobust索引，并使用可信标签。
- 单元测试证明平台不再把防御检查点作为就绪条件。
- 完整测试集通过，且检测器相关测试保持不变。
