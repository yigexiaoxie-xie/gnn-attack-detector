# 累积式通用检测器设计

## 目标

项目始终只保存一个通用攻击检测器。用户既可以一次选择全部数据集，也可以分多次只选择一个或几个数据集；无论采用哪种运行方式，已经成功准备的数据集都继续参与后续训练，并在平台中保留独立的最新评测结果。

## 当前问题

攻击图、清单和特征已经按数据集分别保存，但 `run-selected` 在训练和评测时显式传入本次 `selection.profiles`。因此单选 Cora 后再单选 Citeseer，会用仅含 Citeseer 的训练集覆盖唯一模型，并用仅含 Citeseer 的报告覆盖全局评测文件。磁盘上虽然始终只有一个模型文件，它实际只代表最近一次选择的数据集。

## 核心语义

- `configs/run.yaml` 中的数据集选择只控制本次需要准备、生成或更新的数据集。
- 已存在且校验通过的 `artifacts/features/profiles/<profile>.pt` 是通用检测器的累积训练数据来源。
- 训练阶段合并所有已经准备完成的数据集的 `train` 和 `val` 行，只训练一个模型，并写入现有的 `artifacts/models/universal-attack-detector.pt`。
- 测试图仍只为本次选择的数据集生成；未选择数据集的已保存测试图和特征不重新生成、不删除。
- 新模型训练完成后，评测阶段读取所有已准备且含测试行的数据集，用当前同一个模型重新计算各数据集结果。
- 平台展示每个数据集独立的准确率、攻击图检出率和按攻击方法明细，同时保留综合汇总。

## 运行流程

### 一次选择全部数据集

1. 依次准备所有所选数据集。
2. 分数据集生成训练和验证图及特征。
3. 合并全部已准备数据集，训练一次通用检测器。
4. 分数据集生成测试图及特征。
5. 使用该通用检测器评测全部已准备数据集。
6. 平台可在数据集下拉框中查看每个数据集的独立结果。

### 分批选择数据集

以先运行 Cora、再运行 Citeseer 为例：

1. 第一次运行准备 Cora，并训练只包含当前已准备数据 Cora 的通用检测器。
2. 第二次运行只生成或更新 Citeseer，不重新生成 Cora。
3. 训练阶段自动合并已保存的 Cora 与新 Citeseer 数据，生成新的唯一通用检测器。
4. 评测阶段用新检测器重新评测 Cora 与 Citeseer；Cora 的准确率允许因模型更新而变化。
5. 平台同时显示 Cora 与 Citeseer 的当前结果。

后续增加 Polblogs 或 Pubmed 时采用同一规则。

## 数据与模型持久化

- 每个数据集继续独立保存攻击图目录、JSONL 清单、特征缓存和 profile 特征文件。
- 不新增按数据集划分的模型文件，也不保留多个活动检测器。
- 每次成功训练覆盖唯一通用模型；数据集数量增加，模型数量不增加。
- 全局预测 JSONL 和评测 JSON 每次成功评测后整体重建，内容覆盖所有当前可评测数据集，因此不会因单选运行而丢失其他数据集结果。
- 报告增加 UTC 评测时间和当前模型文件哈希。平台显示这些元数据，用于确认所有页面结果对应当前同一个模型。

## 失败处理

- 只有本次选择的数据集会进入耗时的数据准备和攻击生成步骤。
- 已保存数据缺失、损坏、profile 标识不匹配或特征模式不兼容时，训练或评测明确失败，不静默忽略该数据集。
- 新评测全部计算成功后才替换报告；失败运行不得用不完整的单数据集报告覆盖上一次成功报告。
- 若模型已更新但后续测试或评测失败，旧报告仍可保留，但平台必须通过模型哈希识别其属于旧模型并标注为历史结果，避免冒充当前模型结果。

## 平台展示

- 准确率评测页面继续使用一个数据集选择框。
- 选择框列出所有配置数据集；有保存结果的显示独立指标和攻击明细，没有结果的显示空状态。
- 页面显示当前结果的评测时间与模型短哈希。
- 当报告模型哈希与当前模型不一致时，页面显示“历史模型结果”提示，直到下一次成功全量重评测。

## 兼容性

- 保留现有模型、攻击图、清单、特征和报告路径，避免迁移已有大文件。
- 直接运行 `train-detector` 和 `evaluate-detector` 时继续使用所有已准备 profile 的既有默认行为。
- `run-selected` 不再将本次选择的数据集限制传给通用训练和最终评测；选择仍用于准备和测试生成。
- 旧版报告没有模型哈希或评测时间时仍可读取，但平台标注为旧版历史结果。

## 验证标准

- 单次选择四个数据集，只生成一个模型，报告包含四个独立数据集结果。
- 先单选 Cora，再单选 Citeseer，第二次训练同时使用 Cora 和 Citeseer，且不重新生成 Cora 图。
- 第二次运行完成后，报告和平台同时包含 Cora、Citeseer，二者均由当前模型重新评测。
- 再次只运行 Cora 时，Citeseer 数据不被删除，训练与评测仍覆盖二者。
- 模型哈希与报告一致时显示当前结果；不一致时明确显示历史结果。
- 测试或评测失败时，上一次完整报告保持可读，不出现半份报告。
- 现有多数据集隔离、命令行报告和平台数据集切换测试继续通过。

## 非目标

- 不创建每数据集独立模型。
- 不保存完整模型训练历史或提供模型版本回滚。
- 不自动重新生成未选择数据集的攻击图。
- 不改变攻击方法、样本配额、特征提取算法或检测器网络结构。
